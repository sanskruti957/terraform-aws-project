# Infrastructure as Code (IaC) with Terraform

## Project Description
This project demonstrates Infrastructure as Code (IaC) using Terraform to automate the deployment of an AWS EC2 instance.

## Technologies Used
- Terraform
- AWS EC2
- AWS CLI
- IAM
- VS Code

## Files
- provider.tf - AWS provider configuration
- main.tf - EC2 instance configuration
- variables.tf - Variable definitions
- outputs.tf - Output values

## Commands Used

terraform init

terraform validate

terraform plan

terraform apply

terraform destroy

## Outcome
Successfully deployed an AWS EC2 instance using Terraform.
